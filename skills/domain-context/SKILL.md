# Domain Context

Conductorが依頼とプロジェクト構成からドメインプロファイルを判定する。

## プロファイル選択

- 2Dブラウザーゲーム: 実行モデル、Scene、時間、入力、描画、音、ブラウザー、アセット、
  パフォーマンスを確認する。
- DCCツール: ホストアプリ、プラグインAPI、undo/redo、互換性、アセット形式、
  ホストライフサイクルを確認する。
- ツールアプリ: 永続化、権限、アクセシビリティ、同期、外部連携、再起動を確認する。
- ライブラリ: 公開API、型互換性、semver、シリアライズ、依存関係を確認する。
- 汎用: ドメイン固有リスクがない範囲では通常の仕様・設計・テストを適用する。

## 適用規則

1. プロジェクト固有 `.github/skills/` またはサブモジュールのドメインSkillを優先する。
2. 共有Skillを上書きせず、追加または併読する。
3. プロファイルにない確認項目を一律の完了条件へ混ぜない。
4. ユーザーがドメインを明示していない場合は、明確な証拠に基づいて推定し、
   不明確な場合は仮定として記録する。
