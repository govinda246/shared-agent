# 実装

指定された `tasks.md` を依存順に実装する。

開始前に `hooks.yml` の `before_implement`、各実装フェーズ完了後に
`after_implement` を処理する。

## 原則

- 未読の仕様やADRがある場合は先に読む。
- 進行中のタスクは同時に複数完了させない。
- ドメインロジックをUI、描画、ホストAPIやランタイムから分離する。
- 境界値、キャンセル、再起動、破棄処理を考慮する。
- 数値調整項目は設定値として分離する。
- 各フェーズ後に対象テストを実行する。
- タスク完了時だけ `[X]` を付ける。

外部依存追加、ネットワークアクセス、破壊的操作は事前承認が必要。
