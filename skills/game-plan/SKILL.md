# ゲーム実装計画

`spec.md` と `design.md` を読み、`plan.md` と `tasks.md` を作成する。

完了前に `hooks.yml` の `after_plan` を処理する。

## 手順

1. 共有基盤、Scene、状態、入力、ロジック、UI、アセットの順で分解する。
2. 各ユーザー体験を独立して試せる単位へ分ける。
3. 依存関係、並行可能な作業、検証ゲートを明示する。
4. テストタスクを実装タスクの前に置く。
5. 調整可能なパラメーターをハードコードから分離する。
6. 各タスクへ対象ファイルと完了条件を付ける。

## タスク形式

```text
- [ ] T001 [P] [US1] 対象ファイルに処理を実装する
```

実装、検証、ADR、ドキュメント更新が漏れていないことを確認する。
